## Native KiCad bundle

`testdata/logical/reports/kicad-native/` is a self-contained, synthetic native
reference bundle generated by the tested `generate_native_fixture` example. It
contains the source projection, `.kicad_sch`, object map, project-local symbol
library/table, minimal project anchor, KiCad 10.0.5 ERC report and SVG rendering.
The same directory also contains the real GUI-upgraded save, its project anchor,
parser summary and second zero-violation ERC report. See its `README.md` for the
file-by-file layout.
